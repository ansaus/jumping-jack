# Jumping Jack — Telegram Mini App

Ремейк Jumping Jack (ZX Spectrum, 1983): лягушка прыгает сквозь движущиеся дыры в линиях и должна добраться до верхней линии. Вся игра в одном файле `index.html`, без сборки и без зависимостей.

## Правила
- ◀ ▶ — бег. Можно уйти за край экрана и выйти с другой стороны.
- ПРЫЖОК (или тап по полю) — прыжок вверх. Если над головой нет дыры, лягушка ударяется о линию и ненадолго оглушена.
- Если под тобой проползает дыра, ты падаешь на линию ниже. Если упал на самый низ, теряешь жизнь.
- Каждый удачный прыжок добавляет на поле ещё одну дыру (максимум 8).
- Начиная со 2-го уровня появляются враги. Столкнёшься с врагом — оглушит.
- Дыра, ушедшая за правый край, появляется слева на линии ниже. Дыра, ушедшая за левый край, появляется справа на линии выше.

Очки: +5 × уровень за каждую линию и +100 × уровень за пройденный уровень. Рекорд хранится в Telegram CloudStorage (и в localStorage, если игра открыта вне Telegram).

## Как запустить в Telegram

### 1. Выложить на HTTPS
Telegram открывает Mini App только по `https://`. Самые быстрые варианты:
- **Netlify Drop**: открой https://app.netlify.com/drop и перетащи туда папку `jumping-jack`. Ссылка будет готова сразу.
- **GitHub Pages**: создай репозиторий, положи в него `index.html`, затем Settings → Pages → Deploy from branch `main`.
- **Cloudflare Pages / Vercel**: тоже подходят, это обычная статика.

### 2. Создать бота и подключить игру
В [@BotFather](https://t.me/BotFather):
1. `/newbot`: задай имя и username, получишь бота.
2. `/mybots` → твой бот → **Bot Settings** → **Configure Mini App** → **Enable Mini App** → вставь HTTPS-ссылку.
3. (по желанию) **Bot Settings** → **Menu Button**: та же ссылка и текст кнопки, например «Играть».
4. (по желанию) `/newapp`: создаёт прямую ссылку вида `t.me/<бот>/<app>`, ей удобно делиться.

Код бота писать не нужно: BotFather сам показывает кнопку, которая открывает игру.

## Локальная проверка
Просто открой `index.html` в браузере. Управление с клавиатуры: ← → / A D — бег, пробел / ↑ / W — прыжок.
